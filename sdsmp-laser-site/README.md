# SDSMP 레이저런 (GitHub Pages + Firebase)

성덕 레이저런 리그의 기록 · 중계 사이트입니다. 화면은 GitHub Pages가 보여 주고, 기록은 Firebase(Firestore · Realtime Database)에 저장됩니다.

## 처음 한 번 설정 (관리자)
1. 이 폴더의 파일을 GitHub 저장소에 올립니다 (`fb/config.js`에 Firebase 웹 앱 설정값이 들어 있음 — 공개돼도 되는 값).
2. Firebase 콘솔 › Authentication › 로그인 방법: **Google**, **익명** 사용 설정. 설정 › 승인된 도메인에 `<GitHub아이디>.github.io` 추가.
3. 사이트에서 Google로 로그인합니다. 규칙이 빠졌거나 옛 버전이면 **「Firebase 설정 점검」 화면**이 뜹니다.
   빨간 항목마다 ① 규칙 복사 → ② 규칙 화면 열기 → ③ 전부 지우고 붙여넣기 → 게시 → 「다시 확인」.
4. 「이 대회의 관리자로 등록」을 누릅니다.
5. 왼쪽 아래 「계정 · 권한」에서 체육회 코드와 TV 코드를 정합니다.

## 역할
| 역할 | 들어가는 방법 | 할 수 있는 일 |
|---|---|---|
| 관리자 | Google 로그인(처음 한 명) | 모든 기록 · 설정, 코드 · 권한 관리 |
| 선생님 | Google 로그인 → 편집 권한 요청 → 관리자 승인 | 기록 입력 · 수정, 경기 · 코스 지점 · 설정 |
| 체육회 · 지점 요원 | 이름 + 체육회 코드 | 「지점 버튼」으로 통과 기록, 모든 화면 보기 |
| TV 화면 | TV 코드 | TV 송출, 카메라 고르기, 모든 화면 보기 |
| 스포츠기자단 | 로그인 없음 — CAM QR만 찍기 | 휴대폰 카메라를 TV로 보내기 |

## 경기 당일 흐름
- **코스 지점 · 카메라**(선생님): 지점 위치 · 요원 배정 · 카메라 QR
- **지점 버튼**(요원 폰): 경기가 시작되면 조끼 색 버튼이 켜짐 → 선수가 지나는 순간 누름 (10초 안 취소)
- **TV**: 화면 아래 CAM 버튼 · 숫자 키(1~), 0은 끄기, 「자동」은 선두가 다음에 지나갈 카메라

학생 이름 · 기록은 저장소(GitHub)에 들어가지 않고 Firebase에만 저장되며, 역할이 있는 사람만 읽을 수 있습니다.
규칙을 고치면 `firestore.rules`의 `probe/v3`와 `database.rules.json`의 `probe.v3`, `fb/shim.js`의 `RULES_V`를 함께 올립니다.
